02 / Correction

The previous database/Turso framing was the wrong abstraction.

Kura is the substrate storehouse family. The harness must simulate product worlds from CUJs, not start from database adapters. The old Turso-like bead is now explicitly superseded.

Rejected abstraction

Database harness, Turso-first language, libSQL files, database URLs, and migration scripts as the board-facing milestone.

Correct abstraction

CUJ-derived Kura world seed state. Each CUJ creates a world record that can drive simulation.

Ownership boundary

Vaporize owns proof harnesses and receipts. Kura/Vaults Org owns storehouse and data-engine semantics.
